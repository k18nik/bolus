# Bolus для iPhone

Актуальное приложение — **local-first**: все данные хранятся на iPhone, сервер, аккаунт и интернет не нужны. Интернет используется только для поиска во внешних каталогах еды и для необязательного AI.

1. Откройте `../bolus-assistant/ios/Bolus.xcodeproj` на Mac с Xcode 16 или новее.
2. В Signing & Capabilities выберите свою Apple Team, подключите iPhone и нажмите Run.
3. Пройдите настройку на телефоне. Данные с прежнего сервера переносятся JSON-копией: «Перенести данные из резервной копии» на первом экране или «Настройки → Восстановить из резервной копии».

Подробно: `../bolus-assistant/ios/README.md` (установка и проверка в Airplane Mode) и `../bolus-assistant/docs/LOCAL_FIRST.md` (архитектура, офлайн-матрица, резервные копии).

Прежняя серверная сборка (копия старого `ios/` и `UnsignedArchive/Bolus.xcarchive`) удалена из этой папки: она работала только с сервером. Её можно восстановить из истории git. Архив `../bolus-assistant-source.zip` — снимок исходников прежней серверной версии.
