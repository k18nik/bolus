# Bolus для iPhone (local-first)

Нативное приложение на SwiftUI + SwiftData, iOS 17+. Все данные хранятся на iPhone; сервер, аккаунт и интернет не нужны. Интернет используется только для поиска во внешних каталогах еды (YAZIO / USDA) и для необязательного AI (OpenAI / Tokenn).

Архитектура, матрица офлайн-функций, формат резервной копии и паритет с Python: [../docs/LOCAL_FIRST.md](../docs/LOCAL_FIRST.md).

## Установка через Xcode

1. Откройте `Bolus.xcodeproj` на Mac с Xcode 16 или новее.
2. Target **Bolus → Signing & Capabilities**: выберите свою **Team** и при необходимости уникальный Bundle Identifier. Capability HealthKit с фоновой доставкой (Background Delivery) уже указана в `Bolus/Bolus.entitlements`.
3. Подключите iPhone, выберите его как Run Destination (при запросе включите Developer Mode).
4. Нажмите **Run**.

Адрес сервера вводить не нужно. Для TestFlight: **Product → Archive → Distribute App → App Store Connect** (нужен Apple Developer Program).

## Первый запуск

Мастер настройки предлагает имя, единицы глюкозы, терапию (ICR, ISF, цель, порог коррекции, DIA, максимальный болюс, шаг устройства), отслеживание цикла, питомца и тему. Профиль можно настроить позже — дневник, аналитика и отчёты доступны сразу, калькулятор включается после подтверждения профиля.

### Перенос данных с прежнего сервера

1. В веб-версии Bolus создайте отчёт в формате **JSON** (полная резервная копия).
2. Передайте файл на iPhone (AirDrop, «Файлы»).
3. На первом экране нажмите «Перенести данные из резервной копии» или откройте «Настройки → Восстановить из резервной копии».
4. Проверьте план импорта и подтвердите. Существующие данные не перезаписываются.

## Разделы

Сегодня · Дневник · Добавить запись · Болюс · Еда · Аналитика · Цикл · AI · Отчёты · Профиль · Настройки. Темы: Minimal Light, Minimal Dark, Cat Café, Pink Pastel, Dino, OLED Black, Lilac; иконку приложения можно окрашивать в цвет темы. Помощники: кот, сиамский кот, поросёнок, динозавр, лягушка, выдра, панда.

- **Добавить запись**: глюкоза, калькулятор болюса перед едой, затем еда и активность — они раскрываются и сохраняются только с отметкой; инсулин, начало цикла (дата видна в форме, в дневнике и на «Сегодня»), заметка.
- **Записи можно исправлять**: в карточке записи кнопка «Редактировать» стоит перед «Удалить». Исправление сохраняется как новая версия; у инсулина остаются DIA и шаг на момент введения. Данные из «Здоровья» обновляет синхронизация.
- **«Инсулин в сутки»** не включает базальный инсулин; базальный показывается отдельно.
- **Apple «Здоровье»**: переключатель автоматической синхронизации — при открытии приложения и при появлении новых данных в «Здоровье», в том числе в фоне.

## Структура

| Путь | Назначение |
|---|---|
| `Sources/BolusCore/` | детерминированное ядро: BolusEngine `bolus-v1.1.0`, SafetyLayer, IOBEngine `linear-remaining-v1.0.0`, цикл, аналитика, продукты, AI-контракты, отчёты, резервные копии; точная Python-арифметика |
| `Bolus/Persistence/` | SwiftData-модели (`Models.swift`) и `DiaryStore` — все локальные сценарии |
| `Bolus/Services/` | `HealthReader` (HealthKit → SwiftData), `ReportService` (PDF/CSV/XLSX/JSON), Keychain, Face ID, сеть |
| `Bolus/UI/` | экраны SwiftUI, темы, графики Swift Charts |
| `BolusAppTests/` | тесты SwiftData-сценариев на симуляторе |
| `Tests/BolusCoreTests/` | тесты ядра и общие с Python векторы (`Fixtures/`) |
| `scripts/generate_xcodeproj.py` | генерация `Bolus.xcodeproj` |

`BolusCore` компилируется прямо в приложение (без пакетов и сервера) и отдельно как Swift-пакет для `swift test`. После добавления или удаления Swift-файлов обновите проект:

```sh
python3 scripts/generate_xcodeproj.py
```

## Проверки

```sh
# Ядро: паритет с Python (golden cases, bolus/IOB/analytics/numeric векторы)
swift test

# Приложение и SwiftData-сценарии на симуляторе
xcodebuild test -project Bolus.xcodeproj -scheme Bolus \
  -destination 'platform=iOS Simulator,name=iPhone 16' CODE_SIGNING_ALLOWED=NO
```

То же выполняет GitHub Actions (`.github/workflows/bolus-local-first.yml` в корне репозитория): Python-эталон и воспроизводимость векторов, `swift test` на Linux и macOS, сборка приложения, тесты на симуляторе iPhone и Release-сборка для устройства без подписи.

## Проверка в Airplane Mode на iPhone

1. Установите приложение, выключите Wi-Fi и сотовые данные для Bolus, перезапустите.
2. Добавьте глюкозу и еду, рассчитайте болюс, сохраните фактическую дозу, проверьте IOB.
3. Закройте и снова откройте приложение — данные на месте.
4. «Ещё → Apple «Здоровье»»: включите автоматическую синхронизацию и разрешите чтение; данные появятся в дневнике, повторная синхронизация не создаёт копий.
5. Откройте аналитику, создайте отчёты PDF / CSV / JSON (и Excel) — откроется меню «Поделиться».
6. Включите интернет и проверьте поиск YAZIO и AI со своим ключом.

Шаги 1–5 не требуют сети. Сценарии 2–3 и генерация отчётов автоматически проверяются тестами `BolusAppTests` на симуляторе; разрешения HealthKit и реальные данные часов проверяются только на устройстве.
