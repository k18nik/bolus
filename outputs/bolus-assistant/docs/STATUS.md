# Статус ТЗ 1.0

Результат — рабочая личная версия, дополненная OpenAI / Tokenn, шагом устройства и нативным iOS-проектом с HealthKit. Детали обновления: [PERSONAL_UPDATE.md](PERSONAL_UPDATE.md), [iPhone](../ios/README.md). Это не заявление о выполнении всех пунктов 1–100; оставшиеся этапы перечислены ниже.

| Область | Статус |
|---|---|
| Next.js/React/TS/Tailwind, FastAPI/Pydantic/SQLAlchemy/Alembic | Реализовано |
| Docker Compose, PostgreSQL, Redis, Celery worker, Nginx | Собирается и запускается |
| Регистрация/вход/профиль/сессии/CSRF/Argon2 | Реализовано; email verification и password reset не входят в этот MVP |
| Дневник глюкозы/инсулина/еды/активности/заметок | Одна прокручиваемая форма с необязательными разделами и атомарным сохранением; UI редактирования существующих записей пока нет |
| Bolus, IOB, Safety Layer | Личный режим включён по запросу владельца; bolus-v1.1.0 учитывает шаг устройства и сохраняет его в snapshot |
| Фиасп / Тресиба | Распознавание названия и действующего вещества, проверка типа, быстрый IOB и отдельный базальный учёт; индивидуальная DIA из профиля |
| Временные сегменты/история профиля/snapshots/версия алгоритма | Реализовано |
| Поиск, свои продукты/блюда, нутриенты, recent/favorites | YAZIO вместо FatSecret; реальный публичный поиск проверен, граммы/миллилитры сохраняются в snapshots; USDA остаётся опциональным fallback |
| Цикл/календарь/оценочные фазы | Реализовано; недостаточные или выходящие за длину цикла данные дают unknown |
| Темы/питомцы | 6 тем и 6 selectable mascots; кот — оригинальная иллюстрация, остальные — emoji; полный набор анимаций mascot states не реализован |
| Настройка профиля | После регистрации открывается единая форма терапии с названиями инсулинов, шагами и подтверждением параметров |
| Аналитика/графики/события | Базовые детерминированные метрики и описательное сопоставление тренировок |
| PDF/XLSX/CSV/JSON, фоновые задания, центр загрузок | Реализовано; PDF адаптируется к типу и флагам отчёта |
| Отчёт для врача | Общие метрики, 8 графиков, питание, цикл, профиль и активность; не CGM AGP и не клиническая интерпретация |
| Nutrition/Cycle advanced reports | Базовые таблицы; observed ISF/ICR, confidence, сравнение по нескольким циклам и food-specific postprandial analyses — V1.1/V2 |
| Apple «Здоровье» | ZIP/XML импорт и нативное чтение HealthKit: тренировки, шаги, активная энергия, минуты упражнений, дистанция; ручная синхронизация и обновление записей |
| iOS-приложение | SwiftUI/WKWebView, Xcode-проект, сборка Simulator и arm64 Release archive без подписи; подписанная установка и физическое устройство требуют проверки |
| Автоматическая HealthKit-синхронизация | Фоновая доставка, anchors и перенос удалений не реализованы; синхронизацию запускает пользователь |
| PWA/offline queue | Реализовано; расчёт болюса офлайн запрещён; установка и полное офлайн-тестирование на физическом iPhone не выполнены |
| Аудит/валидация/rate limit/dependency scan | Реализованы; автоматическое шифрование production-секретов/дисков остаётся обязанностью инфраструктуры |
| AI Assistant/Structured Outputs | Responses API через OpenAI / Tokenn, зашифрованный ключ, согласие на агрегаты, история и токены; реальное подключение Tokenn / gpt-5.5 и структурированный ответ проверены без данных дневника |
| Personalization/Episodes/Proposals | Только контракты, не обучение и не готовый движок; V2 |
| Barcode | Endpoint возвращает явное «ещё не реализовано»; UI камеры не обещает работающий сканер |
| CGM/pump/Health Connect | Importer abstraction; интеграции V3 |
| Уведомления | Интерфейс сервиса; push, расписания и reminder delivery ещё нет |
| Retention | Отчёты недоступны для скачивания после 7 дней; очистка просроченных файлов и демо-аккаунтов запускается maintenance-командой |
| HTTPS | Локальный loopback HTTP по умолчанию; шаблон production TLS. Домен и trusted TLS не развёрнуты автоматически |

Структура данных: события реализованы общей таблицей `entries` с типизированными Pydantic payloads, вместо отдельных физических таблиц GlucoseEntry/InsulinEntry/Meal. Нутриенты снимка хранятся внутри записи еды. Терапия и DiabetesProfile представлены версионируемым JSON в `therapy_profiles`; изменения этого решения описаны явно, не скрыты пустыми таблицами.

## Следующие этапы

1. Дальнейшие технические проверки: independent code review, threat modelling, реальное устройство iPhone, CGM time-weighted coverage. О клинической валидации владелец сообщил отдельно; разработчик её материалы не проверял.
2. Контроль изменений внешнего YAZIO API, интеграционная проверка необязательного USDA с его ключом; потоковый импорт больших Apple Health архивов.
3. Остальная V1.1: AI-резюме внутри PDF-отчёта и barcode; AI-чат и разбор отдельного болюса уже реализованы.
4. V2: extraction валидных сопоставимых эпизодов, confounder exclusion, confidence calibration, proposals с user confirmation.
5. V3: подписанное iOS-приложение HealthKit, фоновая инкрементальная синхронизация, source reconciliation, CGM/pump imports.
